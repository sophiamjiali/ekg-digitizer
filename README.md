# ekg-digitizer
Deep learning framework for extracting time-series data from digitized EKG images

## Github Workflow

Please follow the following workflow when working on this project:

1. Create an issue, selecting the appropriate label, project, and milestone values
2. Create a corresponding branch: `<label>/<issue-number>-<short-description>`
4. Create commits with conventional messages (feat:, fix:, docs:, test:, refactor:, chore:, etc.)
5. Create pull requests linking the issue
